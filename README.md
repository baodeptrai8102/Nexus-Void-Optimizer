## 🌟 GIỚI THIỆU TỔNG QUAN

**NEXUS VOID OPTIMIZER (v3.0 PRO)** là Engine tối ưu hóa hệ thống chuyên sâu chạy trực tiếp qua câu lệnh PowerShell (`irm | iex`). Không chỉ dọn rác bề nổi, công cụ can thiệp thẳng vào tầng **Registry**, **ép Unpark 100% nhân CPU**, kích hoạt **MSI Mode (Message Signaled-Based Interrupts)** cho Card đồ họa/Card mạng và tái cấu trúc bộ lập lịch **MMCSS** giúp giải phóng toàn bộ sức mạnh phần cứng, giảm tối đa độ trễ (DPC Latency & Input Lag) khi chơi game.

Mở **PowerShell** với quyền **Administrator (Run as Admin)**, copy câu lệnh dưới đây dán vào và nhấn **Enter**:

